# TrolEnfermería

Web app para estudiar Enfermería (malla UDLA Chile) con quizzes, cálculo de dosis, casos clínicos y una IA troll.

Ábrela en Safari desde el iPhone y usa **Compartir → Agregar a inicio** para instalarla.

Material de apoyo: verifica siempre con tus apuntes, tu escuela y las normas MINSAL vigentes.
